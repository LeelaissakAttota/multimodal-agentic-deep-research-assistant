# deep_research

Python package for the bounded, provider-neutral Multimodal Agentic Deep Research Assistant.

The package contains domain and evidence contracts, specialized agents, orchestration, tools, persistence/memory/context services, runtime controls, FastAPI integration, security helpers, and the Phase 7 offline demo.

Run `python -m deep_research.demo` after installing the project. The demo is deterministic, synthetic, zero-network, and bounded; it is not live research.
